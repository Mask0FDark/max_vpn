# Changelog

## Unreleased

- Реальный MAX-тест: TCP-запрос к локальному тестовому серверу и ответ прошли через сообщения MAX.
- Добавлен экспериментальный обработчик одного ограниченного TCP-запроса и интеграционные тесты.
- Проверено 15 тестов; полноценного потокового VPN и отдельного мобильного клиента пока нет.


- Добавлен формат сообщений запрос/ответ с идентификатором запроса, фрагментацией и устранением дубликатов.
- Реальная проверка отправки и чтения пакета RPC через MAX технического аккаунта прошла успешно.
- Добавлены четыре автоматических теста; всего 13 тестов проходят.
- Это пока протокол сообщений, а не полноценный интернет-туннель.


- Добавлен локальный TCP-прокси HTTP CONNECT на ПК с привязкой к 127.0.0.1.
- Проверен сквозной TCP-обмен через прокси с локальным тестовым сервером; всего девять тестов проходят.
- Транспорт через сообщения MAX к этому прокси ещё не подключён; это не VPN для телефона.


- Добавлен диагностический адаптер для отдельной локальной MAX-автоматизации; реальная отправка и чтение тестового сообщения прошли успешно.
- Добавлены два теста адаптера; всего семь тестов проходят.
- Добавлен GitHub Actions workflow для сборки отладочного Android APK (результат CI ещё не проверен).
- Серверный ретранслятор, связь между устройствами и работа в белых списках по-прежнему не реализованы.


- Добавлен экспериментальный кодек бинарных сообщений `bridge/framing.py` и пять автоматических тестов.
- Подтверждён однопакетный тест передачи через технический чат MAX и обратного чтения (37 байт, 2026-10-08).
- Транспорт между устройствами, VPN и режим белых списков пока не подтверждены.

- Публичные тексты очищены от внутренних сведений о размещении сайта и связях с другими проектами.

- Добавлен Android VpnService как системная точка входа без включения неработающего туннеля.
- Добавлена проверка и запрос разрешения VPN с честным отображением состояния подключения.
- При отсутствии транспорта MAX сервис не создаёт виртуальный интерфейс и не перехватывает трафик.

## 0.1.0 — 2026-10-08

- Начат отдельный публичный проект MAX VPN.
- Добавлен каркас Android-приложения со статусом «VPN не подключён».
- Создан самостоятельный статический сайт без связи с VGA Stream и без формы сбора учётных данных.
- Зафиксированы принцип отдельных MAX-аккаунтов и назначение продукта: доступ к обычному интернету при белых списках, без обещания обхода прочих блокировок.
- Рабочий VPN, механизм входа и транспорт MAX пока не реализованы.
