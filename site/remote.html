APK предназначена для тестирования входа по номеру. Для безопасности API необходима однократная привязка устройства к собственному VPS. Это не регистрация нового аккаунта MAX.

Статус VPN через MAX

Серверный PyMax поддерживает телефонную авторизацию и сохраняет сессию. Android-протокол шифрования и нативный TUN проходят автоматические тесты, но сквозной путь Android → сообщения MAX → VPS → интернет на реальном устройстве не подтверждён. Сессия MAX WebView на телефоне пока требует отдельного входа. Не включайте «Блокировать соединения без VPN» для этой экспериментальной сборки.
