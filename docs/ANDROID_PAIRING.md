# Привязка Android к личному VPS

MAX VPN 0.3.x Preview поддерживает **прямой HTTPS-транспорт к вашему VPS**. Это не передача через мессенджер MAX. Режим MAX не реализован, а вход по номеру MAX не подключён.

## Одноразовая привязка телефона

Код выдаётся только владельцем VPS из SSH:

```bash
cd /home/vga/maxvpn
docker compose exec -T maxvpn-web python -m server.pairing
```

Команда печатает случайный код из 24 шестнадцатеричных символов. Он действителен 24 часа и может быть использован один раз. В Android откройте **«Привязать VPS по одноразовому коду»**, вставьте код, дождитесь сообщения об успехе. Приложение обменивает код на личный ключ доступа исключительно через HTTPS и сохраняет ключ зашифрованным через Android Keystore.

После привязки выдайте системное разрешение на создание VPN и нажмите «Подключить через VPS HTTPS». Приложение сначала проверяет доступ к релею; если проверка не проходит, TUN не включается, чтобы не отрезать телефону интернет.

**Важно:** Не выкладывайте код в публичный чат или репозиторий. Для другого телефона выдайте новый одноразовый код. Этот способ авторизует устройство на вашем VPS, а не личный аккаунт MAX.

## Сервер

- На хосте `/home/vga/maxvpn/.env` лежит `MAXVPN_RELAY_TOKEN` (права 600), не публиковать.
- В контейнер монтируется `./private-data:/app/private-data`; каталог доступен uid 10001 и исключён из Git и Docker build context.
- Команда `python -m server.pairing` генерирует новый код и отменяет предыдущий. При успешном применении файл кода удаляется.
- Запрос `POST /api/pair` защищён TLS, случайным 96-битным кодом, сроком действия и ограничением попыток.
- `wss://max-vpn.mask-0f-darkness.ru/relay/check` проверяет ключ до TUN.
- TCP-трафик пересылается по `/relay/tcp`, UDP по `/relay/udp`. Доступ к непубличным IP запрещён.

## Пока непроверено

Внешний HTTPS через авторизованный WSS-релей на VPS проверен реальными запросами. Реальный Android-телефон с мобильной сетью и системный трафик через `VpnService` до браузера/приложений ещё не проверены. Поэтому APK должна оставаться Preview до тестирования на устройстве.
